# AWS S3 Storage Project

## Project Overview

This project demonstrates my practical understanding of Amazon Web Services (AWS), specifically Amazon Simple Storage Service (Amazon S3).

The objective was to create an S3 bucket, organise files using folders, and upload objects into cloud storage.

## AWS Services Used

Amazon S3 (Simple Storage Service)

AWS Management Console

## Tasks Completed

Accessed the AWS Management Console.

Created an S3 bucket.

Created a folder inside the bucket.

Uploaded an object into the folder.

Verified that the uploaded object was successfully stored.

## Skills Demonstrated

AWS Management Console navigation

Cloud storage management

S3 bucket creation

File and folder organisation

Object uploads

## Project Outcome

Successfully created and configured an Amazon S3 bucket and uploaded an object to demonstrate basic cloud storage management.
